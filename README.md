# VystWorld

Исходный проект сайта Minecraft-сервера VystWorld.

Включает Next.js сайт, Supabase Auth/SQL, интеграцию YooKassa на сервере и исходники Minecraft bridge-плагина. Перед запуском прочитай разделы настройки и безопасности в README проекта.

> Важно: это стартовый проект, не опубликованный сервис. Реальные платежи не включены до настройки провайдеров, переменных окружения и тестирования.
